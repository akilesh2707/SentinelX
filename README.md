# SentinelX

AI-Powered Secure Assessment & Intelligent Proctoring Platform

## Overview

SentinelX is a configurable assessment platform for conducting secure
online assessments, coding contests, and multi-round events with
AI-powered proctoring and real-time security monitoring.

## Core Modules

- Assessment Engine
- Coding Contest Engine
- Event Engine
- Security Policy Engine
- AI Proctoring Engine
- Real-Time Command Center
- Evidence & Incident Management
- Assessment Experience Designer
